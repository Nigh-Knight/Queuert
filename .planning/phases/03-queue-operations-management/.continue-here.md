<decisions_made>

**Phase 3 execution decisions:**
- 1-indexed queue positions: Position 1 = first in line (more intuitive for volunteers than 0-indexed)
- Immediate gap closure on removal: Auto-decrement positions when user removed to prevent gaps
- Session-scoped reorder validation: reorderQueue validates all IDs belong to session (security)
- Position badge 28px circular: Visible but not oversized, always visible on cards
- SafeAreaView for camera notch compatibility: All screens respect device safe areas
- Estimated wait time: 25 minutes per position ahead, shown only for waiting status with position > 1
- Contextual messaging: Different messages guide users based on queue state

**Library integration decision:**
- Used SortableItem-level onDrop instead of Sortable-level: Actual library API differs from research - SortableItem provides better per-item control

**Out-of-band feature decision:**
- Added end session functionality to admin dashboard per user request: Enables session management without accessing Convex database directly
