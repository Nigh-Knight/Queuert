<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete queue management system including:
- Volunteer queue view with position numbers on cards
- Drag-and-drop reordering with confirmation dialog
- Auto-repositioning when users removed from queue
- Service user queue position display with real-time updates
- Search filtering by name
- Manual add user flow (already existed)
  </what-built>
  <how-to-verify>
**Setup:**
1. Start dev server: `npx expo start` and `npx convex dev` in separate terminals
2. Open app on two devices/simulators (or web + mobile)

**Test 1: Volunteer Queue View (QUEUE-02)**
1. Log in as admin, create a session
2. Log in as volunteer, scan session QR to join
3. Add 3-4 test users via "Add User" FAB
4. Verify: Queue tab shows all users with position numbers (#1, #2, #3, #4)

**Test 2: Search Filtering (QUEUE-06)**
1. In Queue tab, type a name in the search bar
2. Verify: List filters instantly to show only matching names
3. Clear search, verify: Full list returns

**Test 3: Drag-and-Drop Reordering (QUEUE-05)**
1. Long-press on user #3's card
2. Drag to position #1
3. Verify: Confirmation dialog appears "Move [Name] to position 1?"
4. Tap "Move"
5. Verify: User is now #1, others shifted accordingly

**Test 4: Auto-Reposition on Removal (QUEUE-04)**
1. Note current positions (1, 2, 3, 4)
2. Remove user #2 (tap Remove, confirm)
3. Verify: Former #3 is now #2, former #4 is now #3
4. No gaps in position sequence

**Test 5: Service User Queue Position (QUEUE-01)**
1. On second device, log in as service user
2. Register and join queue
3. Verify: Status screen shows current position number
4. On volunteer device, remove a user ahead of this user
5. Verify: Position number updates automatically on service user device

**Test 6: Real-time Sync (QUEUE-03)**
1. Open queue view on two volunteer devices
2. On device A, add a new user
3. Verify: User appears on device B without refresh
4. On device A, reorder queue
5. Verify: New order reflected on device B

**Expected Results:**
- All position numbers display correctly and update in real-time
- Drag-and-drop feels smooth (60fps) with confirmation dialog
- Removing users closes position gaps immediately
- Service user sees their position update when queue changes
- Search filters instantly as you type
  </how-to-verify>
