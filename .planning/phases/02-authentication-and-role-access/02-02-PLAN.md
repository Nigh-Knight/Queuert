<task type="auto">
  <name>Task 2: Create QRScanner component</name>
  <files>components/auth/QRScanner.tsx</files>
  <action>
Create the QR scanner component with full permission handling.

**Props interface:**
```typescript
interface QRScannerProps {
  onScanComplete: (qrCode: string) => void;
  onError?: (error: string) => void;
}
```

**Component structure:**

1. **Permission handling:**
   - Use `useCameraPermissions()` hook from expo-camera
   - If permission is null (loading), show loading spinner
   - If permission.granted is false, show permission request screen with:
     - Text: "Camera required to scan QR codes"
     - Text: "Go to Settings > Queuert > Allow Camera"
     - Button: "Request Permission" that calls `requestPermission()`
     - Button: "Open Settings" that calls `Linking.openSettings()`

2. **Camera view (when permission granted):**
   - Use `CameraView` component with:
     - `facing="back"`
     - `barcodeScannerSettings={{ barcodeTypes: ['qr'] }}`
     - `onBarcodeScanned={handleScan}`
     - `style={{ flex: 1 }}`

3. **Overlay:**
   - Position absolute overlay on top of camera
   - Instruction text at top: "Point camera at volunteer QR code"
   - Style: white text on semi-transparent black background
   - Use theme constants for styling (Colors, Typography, Spacing)

4. **Duplicate scan prevention:**
   - Use `useRef<boolean>` for `hasScanned` state
   - In `handleScan`, check `if (hasScanned.current) return;`
   - Set `hasScanned.current = true` before calling `onScanComplete`
   - Reset `hasScanned.current = false` when component mounts (useEffect)

**Imports:**
```typescript
import { CameraView, useCameraPermissions } from 'expo-camera';
import { Linking } from 'react-native';
```

**Do NOT:**
- Use expo-barcode-scanner (deprecated)
- Use old Camera component (use CameraView)
- Forget to handle permission denial with Settings link
