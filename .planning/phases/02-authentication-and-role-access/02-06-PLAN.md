<task type="auto">
  <name>Task 1: Create session validation hook</name>
  <files>hooks/useSessionValidation.ts</files>
  <action>
Create a hook that validates session state in real-time.

**Hook responsibilities:**
1. Load session from AsyncStorage on mount
2. Subscribe to session document in Convex (if sessionId exists)
3. Auto-clear session when Convex session becomes inactive
4. Provide session state to consumers

**Interface:**
```typescript
interface UseSessionValidationResult {
  sessionData: SessionData | null;
  isLoading: boolean;
  isSessionActive: boolean;
  sessionEnded: boolean;  // True when session was active but now ended
  clearSession: () => Promise<void>;
}
```

**Implementation:**

1. **AsyncStorage load:**
   - useEffect on mount calls SessionStorage.load()
   - Set sessionData state
   - Set isLoading = false when done

2. **Convex subscription:**
   - Use `useQuery(api.sessions.getSessionById, sessionData?.sessionId ? { sessionId } : "skip")`
   - "skip" prevents query when no sessionId

3. **Session end detection:**
   - Track previous `session.isActive` value with useRef
   - When session exists and `isActive` transitions from true to false:
     - Set `sessionEnded = true`
     - Call `SessionStorage.clear()`
     - Don't automatically navigate (let consumer handle)

4. **Return value:**
   - sessionData from AsyncStorage
   - isLoading during initial load
   - isSessionActive from Convex query (false if no session or ended)
   - sessionEnded flag for showing "session ended" message
   - clearSession function for manual logout

**Edge cases:**
- No sessionId in storage: isSessionActive = false, sessionEnded = false
- Session not found in Convex: isSessionActive = false
- Convex query loading: isSessionActive = previous value

  <files>components/auth/SessionGuard.tsx</files>
  <action>
Create a wrapper component that handles session-based routing.

**Props:**
```typescript
interface SessionGuardProps {
  children: React.ReactNode;
  onSessionEnd?: () => void;
}
```

**Behavior:**

1. **Use the validation hook:**
   - `const { sessionData, isLoading, isSessionActive, sessionEnded, clearSession } = useSessionValidation();`

2. **Loading state:**
   - While `isLoading`, show full-screen loading spinner
   - Prevents flash of wrong content

3. **Session ended alert:**
   - When `sessionEnded` becomes true:
     - Show Alert: "Session ended by admin"
     - On dismiss, call `onSessionEnd` callback if provided
     - Clear sessionEnded flag (prevent re-showing)

4. **Render children:**
   - Pass session context via React Context (optional, can also just use hook in children)
   - Or simply render children and let them use the hook directly

**Note:** This component does NOT do automatic routing. It monitors state and shows alerts. Routing is handled by the individual entry points (provider.tsx, app/index.tsx).

Update app entry points to auto-route based on saved session.

**app/index.tsx updates:**
This is the app's main entry point.

1. Use useSessionValidation hook
2. While loading, show splash/loading screen
3. When loaded:
   - If sessionData exists:
     - role = "service_provider" -> redirect to (admin)
     - role = "volunteer" -> redirect to (volunteer)
     - role = "service_user" -> redirect to (user)
   - If no session -> redirect to provider (role selection)

**app/provider.tsx updates:**
This is the role selection entry point.

1. Wrap content with SessionGuard for session monitoring
2. Add onSessionEnd callback to navigate back to role selection
3. When role is selected:
   - "Admin" -> router.push('/(admin)')
   - "Volunteer" -> router.push('/(volunteer)')
   - "Service User" -> router.push('/(user)')

**Important navigation patterns:**
- Use `router.replace()` for auto-routing (no back navigation)
- Use `router.push()` for user-initiated navigation

**Session end handling:**
- When SessionGuard detects session end, show alert
- On alert dismiss, navigate to provider (role selection)
