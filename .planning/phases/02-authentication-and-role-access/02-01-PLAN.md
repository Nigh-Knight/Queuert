  <action>
Create a type-safe AsyncStorage wrapper for session data.

**Interface:**
```typescript
interface SessionData {
  sessionId: string;
  role: 'service_provider' | 'volunteer' | 'service_user';
  userId?: string;       // Set for service users
  volunteerId?: string;  // Set for volunteers
  location: string;
  timestamp: number;     // When session was saved (for staleness check)
}
```

**Functions to implement:**
1. `save(data: SessionData): Promise<void>` - Save session with current timestamp
2. `load(): Promise<SessionData | null>` - Load session, return null if not found or stale (>24h)
3. `clear(): Promise<void>` - Remove session from storage

**Key implementation details:**
- Use storage key: `@queuert_session`
- Wrap all AsyncStorage calls in try/catch, log errors with console.error
- In `load()`: Check if session is older than 24 hours, if so clear it and return null
- Export both the `SessionStorage` object and the `SessionData` type

<task type="auto">
  <name>Task 2: Create Convex auth mutations</name>
  <files>convex/auth.ts</files>
  <action>
Create authentication mutations and queries for all three roles.

**1. validateVolunteerQR mutation:**
- Args: `{ qrCode: v.string() }`
- Look up volunteer using `by_qr_code` index
- If not found, throw "Invalid QR code"
- Get session by volunteer.sessionId
- If session not found, throw "Session not found"
- If session.isActive is false, throw "This session has ended. Please contact admin to start a new session."
- Return `{ volunteerId, sessionId, location, role: "volunteer" }`

**2. checkPhoneDuplicate query:**
- Args: `{ sessionId: v.id("sessions"), phone: v.string() }`
- Look up user by phone using `by_phone` index
- If user not found, return `{ isDuplicate: false }`
- Query queue entries for this session with status "waiting" or "washing"
- Filter by serviceUserId matching found user
- If queue entry exists, return `{ isDuplicate: true, message: "This phone number is already in the queue for this session" }`
- If user exists but not in queue, return `{ isDuplicate: false, isReturningUser: true, userId: user._id }`

**3. registerServiceUser mutation:**
- Args: `{ sessionId: v.id("sessions"), firstName: v.string(), lastName: v.string(), phone: v.optional(v.string()) }`
- Validate session exists and is active
- If phone provided, check for duplicate (reuse checkPhoneDuplicate logic inline)
- Create user record with role "service_user", location from session
- Return `{ userId, sessionId, location, role: "service_user" }`

**Index usage (all queries must use indexes):**
- volunteers: `by_qr_code`
- users: `by_phone`
- queue: `by_session_status`

Do NOT use `.filter()` for sessionId or qrCode lookups - use `.withIndex()`.
