<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
Complete authentication system with three distinct flows:
1. Admin verification with code "kepler cool"
2. Volunteer QR scanning with session validation
3. Service user phone/name entry with duplicate detection
Plus session persistence and auto-logout on session end.
  </what-built>
  <how-to-verify>
**Setup:**
1. Start the app: `npx expo start`
2. Start Convex: `npx convex dev`
3. Open on device/simulator

**Test 1: Admin Flow**
1. Select "Admin" role
2. Enter invalid code -> should show error
3. Enter "kepler cool" -> should access admin dashboard
4. Close and reopen app -> should auto-route to admin dashboard
5. Logout -> should return to role selection

**Test 2: Volunteer Flow (requires admin to create session first)**
1. As admin, create a session and generate QR codes
2. Switch to different device/simulator OR logout
3. Select "Volunteer" role
4. Scan QR code with camera
5. Invalid QR -> should show error and stay on scanner
6. Valid QR -> should show dashboard with session info
7. Close and reopen app -> should auto-route to volunteer dashboard

**Test 3: Service User Flow**
1. Select "Service User" role
2. Leave phone blank, enter name only
3. Submit -> should work (phone optional)
4. See queue status screen
5. Go back and try same session with duplicate phone -> should show error

**Test 4: Session End (requires two devices/simulators)**
1. Volunteer is logged into a session
2. Admin ends the session
3. Volunteer should see "Session ended by admin" alert
4. After dismissing, volunteer returns to role selection

**Test 5: Session Persistence**
1. Login as each role
2. Force close app (not just background)
3. Reopen -> should auto-route to correct screen
  </how-to-verify>
