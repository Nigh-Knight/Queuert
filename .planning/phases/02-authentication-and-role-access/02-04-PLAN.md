  <name>Task 2: Create phone/name entry screen</name>
  <files>app/(user)/phone-entry.tsx</files>
  <action>
Create the phone and name entry screen for service users.

**Form fields:**
1. First Name (required, min 2 chars)
2. Last Name (required, min 2 chars)
3. Phone Number (optional, international format with country code)

**Phone number handling:**
- Use TextInput with keyboardType="phone-pad"
- Accept input starting with "+" for international format
- Basic validation: if provided, must start with "+" and be at least 10 chars
- "Skip Phone" option for users without phones

**Form validation:**
- First name: required, min 2 characters
- Last name: required, min 2 characters
- Phone: optional, but if provided must be valid format

**Duplicate detection:**
- Before registration, call `checkPhoneDuplicate` query
- If duplicate, show Alert: "This phone number is already in the queue for this session"
- Stay on form, don't navigate

**Submit flow:**
1. Validate form fields
2. If phone provided, check for duplicate
3. Call `registerServiceUser` mutation
4. On success, save session to AsyncStorage
5. Navigate to queue-status

**UI layout:**
- Use Header component with title "Join Queue"
- InputField atoms for form fields
- CustomButton for "Join Queue" (primary) and "Skip Phone" (secondary)
- Error messages below each field
- Use theme constants for styling

**State:**
- firstName, lastName, phone (form values)
- errors object for field-level errors
- isSubmitting for loading state
