  <name>Task 2: Create QR scan screen with Convex integration</name>
  <files>app/(volunteer)/scan-qr.tsx</files>
  <action>
Create the QR scanning screen that validates codes with Convex.

**Screen structure:**

1. **Import QRScanner component** from `@/components/auth/QRScanner`

2. **State management:**
   - `isValidating: boolean` - Shows loading overlay during validation
   - `error: string | null` - Error message to display
   - `showConfirmDialog: boolean` - For session switch confirmation
   - `pendingSession: object | null` - Session data waiting for confirmation

3. **handleScanComplete function:**
   - Set `isValidating = true`
   - Call `validateVolunteerQR` mutation with scanned QR code
   - On success:
     - Check if user already has a session (load from AsyncStorage)
     - If switching sessions, show confirmation dialog: "Join [Location] session on [Date]?"
     - If confirmed or no existing session, save to AsyncStorage and navigate to dashboard
   - On error:
     - Show error toast/alert with error message
     - Reset scanner to allow retry (set error state, stay on screen)
   - Set `isValidating = false` when done

4. **Error display:**
   - If `error` is set, show error message above scanner
   - Use Alert.alert() for error feedback (simple, native)
   - Clear error when user taps to retry

5. **Session switch confirmation:**
   - Use Alert.alert() with "Cancel" and "Join" buttons
   - "Join [Location] session on [Date]?" format
   - If cancelled, clear pending session and reset scanner
   - If confirmed, save and navigate

6. **Loading overlay:**
   - When `isValidating`, show semi-transparent overlay with ActivityIndicator
   - Text: "Validating QR code..."

**Navigation:**
- On successful validation: `router.replace('/(volunteer)/dashboard')`
- Use `useMutation` from convex/react for validateVolunteerQR
