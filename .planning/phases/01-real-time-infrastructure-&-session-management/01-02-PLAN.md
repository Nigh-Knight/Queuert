<task type="auto">
  <name>Task 2: Migrate Sessions Queries to Use Indexes</name>
  <files>convex/sessions.ts</files>
  <action>
Update getActiveSession query to use .withIndex() instead of .filter():

BEFORE (current code):
```typescript
export const getActiveSession = query({
  args: { location: v.string() },
  handler: async (ctx, args) => {
    return await ctx.db
      .query("sessions")
      .filter((q) => q.eq(q.field("location"), args.location))
      .filter((q) => q.eq(q.field("isActive"), true))
      .first();
  },
});
```

AFTER:
```typescript
export const getActiveSession = query({
  args: { location: v.string() },
  handler: async (ctx, args) => {
    return await ctx.db
      .query("sessions")
      .withIndex("by_location_active", (q) =>
        q.eq("location", args.location).eq("isActive", true)
      )
      .first();
  },
});
```

Key changes:
- Replace .filter() with .withIndex("by_location_active", ...)
- Chain .eq() calls for compound index fields
- Index order matches schema: ["location", "isActive"]
  </action>

  </verify>
