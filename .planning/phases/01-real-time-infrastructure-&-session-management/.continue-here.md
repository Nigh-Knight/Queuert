<decisions_made>

**Session-Specific Decisions:**
1. **Admin verification via phrase (not phone)**: User wanted admin access control without SMS, phrase-based is simpler for MVP
2. **Bottom sheet for create session (not full screen)**: User wanted less intrusive UI, 75% sheet better UX
3. **Custom FAB instead of react-native-paper**: Paper FAB was slow to load, custom TouchableOpacity renders instantly
4. **Global navigation bar with 16px top padding**: Future-proofs all screens, prevents elements from crowding nav buttons
5. **Status bar always dark**: Light background requires dark text for visibility
6. **Allow current time sessions**: Admins need flexibility to start sessions immediately without prep
